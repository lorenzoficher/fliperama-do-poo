# Fliperama do POO

Quiz gamificado para estudar para a Prova 1 de Programação Orientada a Objetos em Java.

**Jogar:** https://lorenzoficher.github.io/fliperama-do-poo/

- 83 questões, todas com explicação: as 30 do quiz da Aula de Revisão e 53 extras
- Modos: Lista do professor, Questões extras, Maratona, Sobrevivência (3 cafés, 25 s por questão) e Revisar erros
- Combo de acertos, recorde por modo, filtro por tema, desempenho por tema no final
- Teclado: `1`–`4` ou `A`–`D` para responder, `Enter` para avançar

Tudo num único `index.html`, sem dependências além das fontes do Google Fonts.
